# Assets

Ce dossier contient les ressources statiques de l'application :

- `logo.png` : Logo de l'application (optionnel)
- `examples/` : Images d'exemple pour la démonstration
- `icons/` : Icônes personnalisées

## Utilisation

Pour ajouter des images d'exemple :
1. Créez le dossier `examples/`
2. Ajoutez vos images de démonstration
3. Référencez-les dans l'application via `assets/examples/nom_image.jpg`
