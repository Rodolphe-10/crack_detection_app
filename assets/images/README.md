# 🖼️ Dossier Images

## 📁 Contenu
Ce dossier est destiné à contenir les images et logos de l'application.

## 🏗️ Logo de l'Application
Pour ajouter un logo à votre application :

1. **Formats supportés** : PNG, JPG, JPEG, SVG, ICO
2. **Taille recommandée** : 150px de largeur maximum
3. **Nom de fichier** : Tout nom (ex: `logo.png`, `icon.jpg`, etc.)

## 📋 Instructions
1. Placez votre fichier de logo dans ce dossier
2. Le logo apparaîtra automatiquement dans la sidebar
3. Si aucun logo n'est présent, un placeholder sera affiché

## 🎨 Conseils Design
- **Fond transparent** recommandé (PNG)
- **Couleurs compatibles** avec le thème noir de l'app
- **Format carré ou légèrement rectangulaire** pour un meilleur rendu
- **Résolution suffisante** pour un affichage net

## 🔄 Rechargement
Après avoir ajouté un logo, rechargez simplement la page Streamlit pour le voir apparaître.
